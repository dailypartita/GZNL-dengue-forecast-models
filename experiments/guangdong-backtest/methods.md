# 广东省登革热月度回测：方法说明

本说明与指标 CSV 一起放在 `experiments/guangdong-backtest/`，供 README「广东省历史回测」一节引用。下面的病例文件路径是实验运行时的工作目录，原始序列和训练代码没有放进本仓库。评价协议、气候处理和模型定义保持实验记录原文。

## 评价协议

- 标签：广东省法定传染病月报口径的本省月度发病数（按现住址，不含港澳台和外籍），序列见 `/workspace/guangdong-dengue/guangdong_dengue_monthly.csv`。不用全国 CDC 病例作训练标签。
- 滚动起点：每月一次。在起点 t，所有拟合、阈值、气候特征和残差只用日期 ≤ t 的信息，预报 t+1…t+h。
- 视野：提前 1–5 个月。
- 公平评价窗：起点 2014-05 至 2026-04，共 144 个起点；每个起点的 t+1…t+5 目标月均已观测（最后目标月 2026-09）。该窗口覆盖 2014-10、2019-10、2023-10、2024-10、2025-10 五个秋峰。
- 缺失规则：2004–2014 年有 25 个月缺失（含 2014-02），一律不按 0 填。需要的滞后月若缺失，则跳过该模型在该起点/视野的预报。
- 分位数：0.05、0.25、0.50、0.75、0.95（同一套用于全部模型）。WIS 按 Bracher 等加权区间评分（含 50% 与 90% 区间及中位数）；覆盖率为 50%（0.25–0.75）和 90%（0.05–0.95）。
- 残差模型从 2010-01 开始预热，只用目标月 ≤ 当前起点的对数残差。

## 气候

- 来源：Open-Meteo Historical Weather API（ERA5 / ERA5-Land），时区 Asia/Shanghai。
- 地点等权平均：广州 (23.13, 113.26)、深圳 (22.54, 114.06)、汕头 (23.35, 116.68)、湛江 (21.27, 110.36)、韶关 (24.81, 113.60)。
- 变量：月平均气温、月降水合计、月平均相对湿度。覆盖 2003-12 至 2026-10，无缺失月，因此气候模型与非气候模型在同一公平窗上比较，没有更短的气候子窗。
- 禁止使用中国全国平均 ERA5。Zenodo 记录 10.5281/zenodo.18391003 的 `guangdong_climate_2016_2024.xlsx` 已下载，但时段短于主序列，仅作备查，未用于主回测。
- LightGBM 气候特征只用滞后 1 个月（及截至 t−1 的 3 个月滚动）。温度可感性模型在起点 t 使用当月气候（月报发布时该月已结束，属于 known-at-origin）；更远步用起点之前的同月气候学平均，不用未来实况。

## 白纹伊蚊温度可感性（转移，非广东拟合常数）

采用 Yan–Hunt beta 型热力曲线，峰值在 Topt，Tmin / Tmax 处为 0。界限取自 Mordecai et al. 2019, *Ecology Letters* 表 2：DENV 在 *Aedes albopictus* 中 Tmin=16.2°C、Topt=26.4°C、Tmax=31.4°C。不是巴西 / 埃及伊蚊常用的 22°C 阈值，也不是用广东数据估出的生物学常数。

## 模型

1. **seasonal_naive**：历史同月中位数（仅用 ≤ t 的观测），区间为同月经验分位数。不用“去年同月”单点，以免 2020–2022 低发年后把基线锁死。
2. **negbin_seasonal**：按视野直接拟合 NB2 GLM：log(μ)=目标月效应 + β log(y_t+0.5)。过离散参数 α 用泊松 Pearson 残差的中位数估计，并截断在 (10^{-6}, 5]。预测分位数来自负二项分布。
3. **loglinear**：按视野 OLS：log(y_{t+h}+0.5)=目标月效应 + β log(y_t+0.5)。区间由因果滚动对数残差变换回原尺度，中位数本身不移动。
4. **growth_regime**：两机制迭代月增长。阈值 τ=max(20, 3×淡季中位数, 淡季 P90)，淡季为 12–5 月；机制权重为 log(当前水平/τ) 的 logistic。流行机制用历史同月增长中位数（起点水平已高时向高起点子样本收缩）；11–12 月允许增长 <1；不以历史最高值截断。地方性机制用从当前水平出发、受抑制的增长，而非被暴发抬高的同月中位数。τ 与增长统计只在 ≤ t 的数据上重算。区间同上，用对数残差。
5. **lgbm_lag**：LightGBM 分位数回归（log1p 空间），特征仅为滞后与日历（lag1/2/3/6/12、近 3 月均值、一阶差分、月正弦余弦）。200 轮、15 叶。
6. **lgbm_climate**：同上，外加滞后 1 个月的广东气温、降水、湿度、3 个月滚动和白纹伊蚊 S(T)。
7. **climate_suitability**：一步对数增长 = 目标月效应 + β S(T) + γ 降水距平，只在 ≤ t 上拟合；多步迭代，未来步用气候学。为避免静默年从低基数爆炸，用与 growth_regime 相同的 τ / 机制权重做轻度地方性混合。这不是把气候当作 LightGBM 的额外列。
8. **ensemble_median**：对 growth_regime、loglinear、negbin_seasonal、climate_suitability、lgbm_climate 的同名预测分位数取中位数（COVID-Hub / IMDC 风格）。不含 seasonal_naive。若某成员缺失，则用其余成员（至少 2 个）。

未把 LSTM / 深度学习作为主比较。

## 已知缺口

- 2014-07、2015-01 两个起点的 lag6 / lag12 落在缺失的 2014-02，LightGBM 两个变体在这两点的 5 个视野共 10 次预报被跳过（n=710，其余模型 n=720）。
- 除此以外，8 个模型在公平窗内均成功出数，没有拟合失败。
